User Registration Form

Project Description

This project is a simple user registration form built with HTML. It was created for Week 02 – HTML Forms (Task 01).

The form demonstrates different HTML form elements and HTML5 validation.

Features

- Personal information: Full Name, Email, Password, Confirm Password, and Date of Birth.
- Contact information: Phone Number, Address, and City Selection.
- Preferences: Gender Selection, Interests, and Skill Level.
- Profile Picture Upload (Images Only).
- Required Terms and Conditions Checkbox.
- Register and Clear Form Buttons.

HTML Elements and Validation

- "<fieldset>" and "<legend>" group related form fields.
- "<label>" connects a text label to its input.
- "required" makes a field mandatory.
- "minlength" sets the minimum number of characters.
- "pattern" checks the phone number format.
- "type="email"" provides automatic email validation.
- Radio buttons allow one choice in a group.
- Checkboxes allow multiple choices.
- The range input selects a skill level from 1 to 10.
- The file input accepts image files only.

How to Run

1. Save the code in a file named "registration-form.html".
2. Open the file in a web browser.
3. Fill in the form and test the required-field validation.
4. Use Register to submit or Clear Form to reset the fields.
