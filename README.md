# User Registration Form
 
A simple user registration form built using HTML5 for Week 02 – Web Development 1.
 
## Project Description
 
This project is designed to create a complete registration form using different HTML form elements and HTML5 validation.
 
## Features
 
- **Personal Information:** Full Name, Email, Password, Confirm Password, and Date of Birth.
- **Contact Information:** Phone Number, Address, and City Selection.
- **Preferences:** Gender, Interests, and Skill Level.
- **Profile Picture:** Upload an image file.
- **Terms and Conditions:** Required agreement checkbox.
- **Buttons:** Register and Clear Form.

 
## HTML Elements Used
 
- fieldset and legend – Group related form elements.
- label – Describe each input field.
- input – Create different types of form inputs.
- textarea – Enter address information.
- select – Display a dropdown list.
- radio – Select one option.
- checkbox – Select multiple options.
- range – Select skill level.
- button – Submit or reset the form.

 
## HTML5 Validation
 
- required – Makes fields mandatory.
- minlength – Sets the minimum number of characters.
- pattern – Validates the phone number format.
- type="email" – Validates the email format.
- accept="image/*" – Allows image files only.

 
## How to Run
 
1. Download or clone the repository.
2. Open registration-form.html in a web browser.
3. Fill in the registration form.
4. Test the validation by submitting the form
